

# 📖 Quran Reels

Scroll through the Quran one ayah at a time, just like reels. Read, listen and save the ayahs you love.

## ✨ Features
- One ayah per screen, vertical scrolling
- Arabic text with Bangla translation
- Surah name and ayah number shown as reference
- 🔊 Recitation audio (Mishary Alafasy)
- ⬇️ Download your favorite ayahs and listen offline
- 100% free, no ads

## 📲 How to Install
1. Tap the button above to download the APK
2. Open the file. If asked, allow **Install unknown apps**
3. If Google Play Protect shows a warning, tap **Install anyway**
4. Open the app and start reading
